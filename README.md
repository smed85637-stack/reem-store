# متجر ريم الإلكتروني - نسخة Supabase

هذه النسخة مربوطة بـ Supabase حتى تظهر المنتجات لكل الزوار من كل الهواتف.

## الملفات
- `index.html`: التطبيق الرئيسي
- `vercel.json`: إعداد بسيط لـ Vercel

## مهم
قبل استعمال الموقع تأكد من وجود جدول `products` و bucket باسم `product-images` في Supabase، وأن السياسات التي تسمح بالقراءة والإضافة والتعديل والحذف تعمل.
